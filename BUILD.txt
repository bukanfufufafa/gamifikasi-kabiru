blockly.min.js dibuat dari folder blockly-main (Blockly 13.4.0) tanpa mengubah kodenya:
  1) cd blockly-main/packages/blockly
     tsc -p tsconfig.json --outDir _build --declaration false --declarationMap false --sourceMap false --incremental false
  2) letakkan folder blockly-main sejajar dengan folder proyek, lalu dari folder proyek:
     esbuild entry.js --bundle --minify --format=iife --target=es2020 --legal-comments=none --outfile=blockly.min.js
  3) salin isi blockly-main/packages/blockly/media ke folder proyek
Game hanya perlu blockly.min.js dan berkas media yang sudah jadi; langkah ini hanya jika ingin upgrade Blockly.
